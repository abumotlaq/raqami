# Neutral Placeholder Design Tokens

These neutral placeholders are provisional and pending UI/UX designer approval. They are not a finalized visual design.

All tokens are defined in `src/index.css` inside `@theme`.

## Colors

| Token | Value | Intended use |
| --- | --- | --- |
| `primary` | `#404040` | Neutral placeholder for primary actions |
| `primary-foreground` | `#ffffff` | Content on primary surfaces |
| `secondary` | `#737373` | Neutral placeholder for secondary actions |
| `secondary-foreground` | `#ffffff` | Content on secondary surfaces |
| `background` | `#f5f5f5` | Neutral gray page background |
| `surface` | `#ffffff` | Cards and raised content |
| `text` | `#171717` | Neutral near-black main text |
| `muted` | `#737373` | Neutral gray secondary text |
| `border` | `#d4d4d4` | Neutral gray borders and separators |
| `danger` | `#525252` | Neutral dark gray error and destructive states |
| `success` | `#404040` | Neutral dark gray success states |
